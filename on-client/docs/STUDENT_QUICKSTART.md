# 케셰브 실행 안내 한 장

처음 보는 사람이 이 한 장만 보고 앱을 켜고, 내 PC 점검 요약을 확인하고, 끄고, 다시 켤 수 있게 쓴 안내입니다. 관리자 권한, API 키, 회사 계정은 필요하지 않습니다.

## 준비물

| 준비물 | 확인 방법 |
|---|---|
| Windows PC와 PowerShell | 시작 메뉴에서 PowerShell 실행 |
| Node.js 22~24 (권장 24.19.0) | `node --version` → `v22`~`v24`로 시작해야 함. 아니면 https://nodejs.org 에서 설치 후 **PowerShell 창을 새로 엶** |
| Git | `git --version` |

추가로 설치할 npm 패키지는 없습니다. 앱 폴더(`on-client`)에는 외부 의존성이 없습니다.

## 1. 받기

빈 폴더에서 PowerShell을 열고 실행합니다. 이미 받은 폴더가 있으면 그 폴더를 쓰고 새로 받지 않습니다.

```powershell
git clone https://github.com/rnjswnghl/keshev.git
Set-Location .\keshev\on-client
```

Git 최상위(`keshev`)에도 `package.json`이 있지만 그것은 1~12단계 자료실입니다. 앱은 반드시 **`on-client` 폴더**에서 켭니다.

## 2. 켜기

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -NoNativeHost
```

- `케셰브가 켜졌습니다. 브라우저에서 http://127.0.0.1:5189/ 을 여세요.`가 보이면 브라우저에서 그 주소를 엽니다.
- `-NoNativeHost`는 계정 연결용 개인 설정을 만들지 않는 로컬 실행입니다. 계정·AI 연결은 담당자가 발급한 권한이 있을 때만 쓰므로 처음 보기에는 필요 없습니다.
- 실행 도구 없이 켜려면 같은 폴더에서 `npm start`를 써도 됩니다. 이때는 `케셰브 연결 확인: http://127.0.0.1:5189`가 나옵니다. 여기서 '연결 확인'은 주소를 알려 주는 문구일 뿐이며 회사 서버 연결에 성공했다는 뜻이 아닙니다. Node 버전과 포트는 미리 확인하지 않습니다.
- 예제 자료로 계정·판정·기록 화면까지 보고 싶으면 `-NoNativeHost` 대신 `-Demo`를 붙입니다. 예제 화면은 실제 자료가 아니며, 캡처할 때도 예제라고 밝힙니다.

## 3. 첫 화면에서 확인할 것

1. 「보호 현황」의 **학생 상태·알림 표시** 칸 맨 위에 「내 PC 점검 요약」이 있습니다.
2. 「다시 조회」를 누릅니다(Tab으로 이동해 Enter·Space로도 누를 수 있음). 「새로 읽는 중…」 뒤에 측정 시각과 `실측 n/6 · 확인 불가 m개`가 나오면 정상입니다.
3. 한 번 더 누르면 직전 조회 대비 변화와 최근 조회 기록(최대 5건)이 나옵니다.
4. 「업무 앱」 「보안 기록」 메뉴의 학생 칸은 기본 실행에서 `ENGINE_NOT_CONNECTED`(SDP 미연결)를 보여 주는 것이 정상입니다.

값의 뜻: **실측**은 이 PC에서 방금 읽은 값, **확인 불가**는 읽지 못한 값과 그 이유, **SDP 미연결**은 회사 접근 제어 서버에 연결하지 않았다는 뜻입니다. 예시 값은 이 칸에 쓰지 않습니다.

## 4. 끄기와 다시 켜기

- 끄기: 앱을 켠 PowerShell 창에서 `Ctrl+C`. 브라우저 주소가 더 이상 열리지 않으면 꺼진 것입니다.
- 다시 켜기: 같은 `on-client` 폴더에서 2번 명령을 다시 실행합니다. 켜고 끄는 동안 프로젝트 파일은 바뀌지 않습니다.

## 5. 막혔을 때

| 보이는 문구·증상 | 원인 | 할 일 |
|---|---|---|
| `Node.js 가 없습니다` / `앱은 Node.js 22~24 에서 실행합니다` | Node가 없거나 버전이 다름 | 24.19.0 설치 → **새** PowerShell 창에서 다시 실행 |
| `npm error Missing script: "start"` 또는 `start-alekov.ps1` 없음 | `on-client`가 아닌 폴더에서 실행 | `Set-Location .\on-client` 뒤 다시 실행 |
| 포트 사용 중 안내 | 이미 켠 앱이나 다른 프로그램이 5189를 씀 | 다른 프로그램을 끄지 말고 끝에 `-Port 5190`을 붙이고 주소도 5190으로 엶 |
| 「확인 불가 · 이 운영체제에서는 읽지 않습니다」 | 방화벽·Windows 기록은 Windows에서만 읽음 | 정상. 값을 만들어 넣지 않음 |
| 「확인 불가 · 일반 권한으로 읽을 수 없습니다」 | PC 정책상 일반 권한으로 못 읽는 항목 | 관리자 권한으로 바꾸지 않고 그대로 둠 |
| 「PC 상태를 읽지 못했습니다 (…)」 | 조회 실패·시간 초과 | 앱 창이 켜져 있는지 확인 후 「다시 조회」. 계속되면 「도움정보 불러오기」 결과를 담당자에게 전달 |
| `ENGINE_NOT_CONNECTED`, `NATIVE_HOST_DISABLED` | SDP·계정 연결을 설정하지 않은 기본 실행 | 정상. 실제 연결은 담당자가 발급하는 개인 인증서가 있어야 열림 |

방화벽·보안 설정을 끄거나 바꾸라는 안내는 따르지 않습니다. 이 앱은 읽기만 합니다.
