# 케셰브 릴리스 기록

## 현재 버전

**`0.2.21-student.final` · 검증 중인 버전 (v1.0 아님)**

마무리 단계에서 시작 틀을 0.2.21로 갱신하고 「내 PC 점검 요약」을 더했습니다. 확인 기록은 [완성본 기록](STUDENT_FINAL.md)에 있습니다. 아래 표는 22단계 제출 당시(`0.2.11-student.22`)의 기록이며 그대로 보존합니다.

### 22단계 제출 당시

| 항목 | 값 |
|---|---|
| 시작 틀 | on-client/package.json `0.2.11` (제공 파일, 버전 문자열 변경하지 않음) |
| 학생 구현 | 13~20단계 학생 표시 함수 8개, 21단계 설명서·구성도, 22단계 재현 기록 |
| 재현 기준 커밋 | `2ed7dbf6cb9714600f078be634e5a5a55ce7ebb6` ([재현 기록](STUDENT_REPRODUCTION.md) 1절의 트리 해시로 제출 커밋과 대조) |
| 기록일 | 2026-10-30 |

v1.0은 19단계 실제 실행 연결과 22단계의 같은 최종 소스 누적 재현·공식 접수 연결이 모두 완료·수용된 경우에만 표시합니다. 아래 「기다림(UNV)」 항목이 남아 있으므로 이번 버전에는 v1.0을 붙이지 않습니다. 22단계 원문 검토를 통과하더라도 그것은 원문 기준 수료이며, 실제 운영 인증이나 v1.0 자동 인증이 아닙니다.

## 지원 범위

| 구분 | 내용 |
|---|---|
| 실행 확인 | 기준 커밋 `2ed7dbf`를 새 폴더에서 Linux Node.js v22.23.4로 실행: 기본·예제 서버 시작·종료·재실행, 학생 함수 8개의 표시 동작. 21단계의 Node.js v24.22.1 실행은 다른 커밋(`b323df9`)의 별도 기록이며 이 버전의 재현 결과에 합산하지 않음 |

| 계약 입력으로만 확인 | 17 AI 연결 오류, 18 설명 결속, 19 조치 효과 관측 구분 |
| 지원하지 않음 | 학생 함수의 직접 네트워크 요청, 주소·열쇠 입력 칸, 학생 조치 버튼, 자동 재요청 |

## 기다림(UNV)

다음 항목은 학생 혼자 완료할 수 없는 운영 측 연결이거나 아직 실행하지 않은 확인입니다. 완료로 기록하지 않습니다.

| 항목 | 상태 | 필요한 것 |
|---|---|---|
| 19단계 실제 조치 집행 연결 | 미완료 | 원천 집행기 연결, 같은 학생·프로젝트·대상의 효과 관측 |
| 실제 계정 SDP·XDR 자료 | 확인 불가 | 담당자 발급 호스트 설정과 계정 연결 확인 |
| 17·18단계 실제 AI 연결·사건 설명 | 확인 불가 | 앱 승인과 AI 게이트 권한. 유료 요청은 임의로 하지 않음 |
| 20단계 실제 OSV 조회 | 확인 불가 | 조회 대상 프로젝트와 공개 승인 목록 설정 |
| Windows PowerShell 실행기·포트 5189·PC 브라우저 조작 | 미확인 | 학생 PC에서 직접 확인 |
| 21·22단계 공식 접수·판정 | 미확인 | 포털 제출 뒤 서버 상태·판정 설명 확인 |

## 알려진 미해결 사항

| 사항 | 영향 | 처리 |
|---|---|---|
| 제공 src/server.mjs가 응답 meta.starterVersion과 도움정보 version을 `0.1.0`으로 출력 | 도움정보에 복사되는 version이 package.json `0.2.11`과 다름 | 제공 서버라 수정하지 않음. 버전 문의 시 package.json 값을 함께 적음 |
| 제공 docs/AI_SETUP_GUIDE.md·tools/start-alekov.ps1이 매니페스트 기준 해시와 다름 | 받은 시작 틀 자체의 차이로 판단, 학생 수정 이력 없음 | 보존. 시작 틀 업데이트는 별도 절차 |
| 과제 화면이 최신 시작 틀 0.2.21을 안내 | 마무리 단계에서 `d5bbf87`로 갱신 완료. 공식 도구는 학생 README 때문에 멈추는 상태라 같은 해시 규칙으로 적용 | 0.2.21 이후 확인은 STUDENT_FINAL.md에 따로 기록 |
| Node.js 22에서 SQLite 실험 기능 경고 출력 | 시작 로그 한 줄. 동작 영향 없음 | 권장 24.19.0 사용 |
